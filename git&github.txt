Git ke 3 Main Areas
1. Working Directory

Yaha hum normal coding ya file editing karte hain.
Jo bhi changes hum likhte hain, woh sabse pehle yahi rehte hain.

2. Staging Area

Yaha woh files jaati hain jinhe hum commit ke liye ready karte hain.
Git yaha changes ko temporarily store karta hai.

3. Repository (Repo)

Yaha final saved version rehta hai.
Commit karne ke baad changes repository mein save ho jaate hain.

Important Commands
1. git init
git init
Isse current folder Git repository ban jaata hai.
Git humare files aur changes ko track karna start karta hai.
2. git status
git status
Is command se hum current status dekh sakte hain.
Kaunsi file tracked hai, modified hai, ya untracked hai sab pata chalta hai.
File Status Samjho
(U) → Untracked

Matlab:

File Git ke andar abhi track nahi ho rahi hai.

Example:

U index.html
Isko track karne ke liye:
git add .

Ya specific file:

git add index.html
(A) → Added

Matlab:

File staging area mein chali gayi hai.
Ab commit ke liye ready hai.
(M) → Modified

Matlab:

File mein changes hue hain.

Example:

Pehle git add . kiya.
Phir file mein kuch aur likh diya.

Ab Git compare karta hai:

Working Directory
VS
Staging Area

Git dekhta hai:

“Working directory mein naye changes hain, lekin staging area mein update nahi hue.”

Isliye file ke saamne (M) dikhata hai.

Important Flow
Working Directory
        ↓
    git add .
        ↓
   Staging Area
        ↓
    git commit
        ↓
    Repository
Extra Help Command
git add -h
git add ke saare options aur help dikhata hai.
